# SOV-5037: Create USDT0 Lending Pool

## Overview
This document outlines the step-by-step process for creating and configuring the USDT0 lending pool in the Sovryn protocol.

## Prerequisites
- Access to the multisig wallet
- USDT0 token contract deployed
- USDT0 price feed contract deployed
- Sufficient USDT0 tokens for initial liquidity
- WRBTC for pool creation and transactions

## Steps

### 1. Deploy Loan Token Contract
Deploy the iUSDT0 lending pool contract with the following parameters:
```python
deployLoanToken(
    conf.contracts['USDT0'],        # token address
    'iUSDT0',                       # symbol
    'iUSDT0',                       # name
    6000000000000000000,           # base rate (6%)
    15000000000000000000,          # rate multiplier (15%)
    75000000000000000000,          # kink level (75%)
    150000000000000000000,         # scale rate (150%)
    [conf.contracts['WRBTC'], 
     conf.contracts['SOV']]         # collateral tokens
)
```

### 2. Set Price Feed
Configure the price feed for USDT0:
```python
setPriceFeed(conf.contracts['USDT0'], conf.contracts['USDTPriceFeed'])
```

### 3. Initial Liquidity Provision
Add initial liquidity to the lending pool:
```python
lendToPool(conf.contracts['iUSDT0'], conf.contracts['USDT0'], 5000e18)
```

### 4. Testing
Verify the lending pool functionality:
```python
testBorrow(
    conf.contracts['sovrynProtocol'],
    conf.contracts['iUSDT0'],
    conf.contracts['USDT0'],
    conf.contracts['SOV'],
    100e18
)
```

### 5. Adding Liquidity into the AMM Pool (Optional)
If needed, to add liquidity to the USDT0/WRBTC AMM pool:
```python
addLiquidityV1(
    conf.contracts['ConverterUSDT0'],
    [conf.contracts['WRBTC'], conf.contracts['USDT0']],
    [0.0002e18, 5e18]
)
```

### 6. Creating AMM Pool
To create the USDT0 AMM Pool:
1. Use the [deployment/converters](https://github.com/DistributedCollective/oracle-based-amm/tree/deployment/converters) branch from the oracle-based-amm repository
2. The configuration has been added in [this commit](https://github.com/DistributedCollective/oracle-based-amm/commit/fd8e6aa1527c4c900420d8b192931aa58eab03d1)
3. Execute the `addConverter.js` script to deploy the pool
